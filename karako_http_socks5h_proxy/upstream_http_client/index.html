Pooled HTTP client whose transport is a SOCKS5 connection.

hyper-util’s legacy client handles pooling, retries and HTTP/1.1 framing; the only custom part is SocksConnector, which opens a fresh SOCKS5 connection whenever the pool needs one. Because the connector receives the destination URI, host names still reach the SOCKS5 server unresolved.

Idle-timeout wrapper for streamed response bodies.

A slow or stalled upstream must not pin a client connection forever. IdleTimeoutBody watches the gap between body frames and turns a stall into a body error, which ends the response cleanly instead of leaving the socket open.

Structs§

IdleTimeoutBody 🔒
Wraps a streaming body so that a stall longer than idle between frames terminates the stream instead of holding a client connection (and its upstream socket) open forever.
IdleTimeoutError 🔒
Error produced when the idle timer expires; surfaced through the body so hyper can abort the response.

Connection-level HTTP service shared by both protocol versions.

hyper-util’s auto server detects HTTP/1.1 versus HTTP/2 and calls ProxyService for each request or stream. The service enforces optional client authentication, dispatches to the version-specific handler, and converts any error into the status code carried by ProxyError.

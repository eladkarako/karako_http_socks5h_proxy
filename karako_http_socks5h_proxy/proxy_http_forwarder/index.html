Module proxy_http_forwarder 

Source
Expand description

Translates inbound requests into upstream HTTP/1.1 requests.

This is the forward-proxy core. It works out which origin the client meant, rebuilds the request line and Host for that origin, removes headers that must not cross a proxy, and streams the response back without buffering it.

CONNECT does not pass through here: it needs a raw tunnel, so crate::http_connect_tunnel handles it instead.

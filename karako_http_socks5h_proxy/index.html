Entry point and connection lifecycle.

Startup goes: parse arguments, install logging, publish buffer tuning, build the shared upstream client, bind the listener, then accept until a shutdown signal arrives. Every accepted socket gets a permit from a semaphore so the process cannot be pushed into unbounded concurrency.

Shutdown stops accepting, gives in-flight connections a short grace period, and aborts whatever is left. A second Ctrl+C skips the grace period entirely.

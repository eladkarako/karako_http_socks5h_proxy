Command-line surface for the proxy.

clap derives --help from the doc comments on Args and its fields: the first line of each comment becomes the short help shown by -h, and any following paragraph becomes the long help shown by --help. Keep those comments descriptive enough to stand alone.

parse_and_validate is the only entry point the rest of the program uses; it resolves the SOCKS5 password sources and rejects configurations that would fail later anyway.

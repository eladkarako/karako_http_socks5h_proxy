Module tcp_socket_config

Expand description

Per-role socket settings.

Each socket the proxy opens has a different traffic pattern, so the buffer sizes and keepalive timings live in named SocketConfiguration constants instead of one global default. Everything here is best-effort: an unsupported option is logged and the connection continues.

Command-line overrides from crate::runtime_buffer_tuning replace the receive/send sizes for every role at once.

those are the documentation for the `karako_http_socks5h_proxy` project,  
as this is a client, and not a lib,  
it can just help you understand the structure and not actually API you can use.  
still it is quite helpful if you want to dig through the structure and have a look  
on how the proxy actually works,  
you can use it if you came across inconsistency in the documentation,  
as this documentation is directly generated from the code, and version.  

<hr/>

note that as the documentation isn't really something that needs a git I only use this branch (`gh-pages`)  
to hold the most recent version generated by `cargo doc --verbose --no-deps --document-private-items --message-format human --color always --release --open`.  

the following git commands purge the git history (leaving only single last version of the documentation).

```
git clone --verbose --progress  --depth 1 --branch "gh-pages"  "https://github.com/eladkarako/karako_http_socks5h_proxy" "gh-pages__karako_http_socks5h_proxy"
git checkout --orphan tmp-rewrite
git add -A
git commit -m "26.11.14"
git push --force origin tmp-rewrite:gh-pages
git checkout gh-pages
git branch -D tmp-rewrite
```
